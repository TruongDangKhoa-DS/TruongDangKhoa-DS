I work in data science and build practical software and web tools under the Exomaly brand ([exomaly.com](https://exomaly.com)): a laboratory system that predicts turnaround time and flags unusual results, plus everyday tools for video, images and translation. Infall and Upscale do all their work on your own device; Remux sends only the file's index to the server, so picture and sound never leave your device.

Main tools: Python (data analysis and models), JavaScript, SQL, Monkey C.

## Laboratory System

| Product | What it does | Address |
|---|---|---|
| **LIMS** | Laboratory management to ISO/IEC 17025: sample receipt, results, review, test reports; turnaround-time prediction and anomaly detection in results | [lims.exomaly.com](https://lims.exomaly.com) |

## Everyday Tools

| Product | What it does | Address |
|---|---|---|
| **Infall** | Download videos (up to 4K) and pictures from YouTube, Facebook, Instagram, TikTok, X and Pinterest, or extract MP3 / M4A audio; a Windows app | [infall.exomaly.com](https://infall.exomaly.com) |
| **Remux** | Fixes the container of an MP4 file before posting to TikTok; picture and sound stay byte-for-byte identical | [upload.exomaly.com](https://upload.exomaly.com) |
| **Upscale** | Upscales images to 2K or 4K right in the browser; your image never leaves your device | [upscale.exomaly.com](https://upscale.exomaly.com) |
| **Geulbit** | Translates Korean text in a photo into Vietnamese: take or pick a picture, the translation appears over the original words, with a vocabulary list | [geulbit.exomaly.com](https://geulbit.exomaly.com) |

Source code is kept in private repositories. Infall release builds are available at [exomaly-download](https://github.com/TruongDangKhoa-DS/exomaly-download).
