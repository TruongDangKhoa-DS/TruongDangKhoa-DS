Exomaly Upscale

Phóng ảnh lên 2K hoặc 4K ngay trong trình duyệt, ảnh không rời khỏi máy bạn.Upscales images to 2K or 4K right in the browser, your image never leaves your device.

Mở sản phẩmOpen the product →

1Tóm tắtSummary

  • Ảnh không rời máy người dùng: không máy chủ xử lý, không tài khoản, không lưu ảnh. Mọi phép tính chạy trên card đồ hoạ (GPU) của chính máy đó: WebGPU, nếu không có thì WebGL, nếu không nữa thì CPU.
  • Miễn phí và không giới hạn lượt dùng, vì máy của người dùng làm việc: chủ dự án không phải trả tiền cho GPU máy chủ.
  • Bốn bộ lọc nâng cấp ảnh (giấy phép BSD-3): hai bản Nhanh (2,4 MB và 1,2 MB) đi kèm trang, hai bản Chất lượng cao (33,4 MB và 8,9 MB) chỉ tải khi được chọn.
  • Không framework, không bước build: HTML, CSS và 14 module ES chạy nguyên bản.
  • Images never leave the user's device: no processing server, no account, no stored images. All the maths runs on that device's own GPU: WebGPU, else WebGL, else CPU.
  • Free with no usage cap, because the user's device does the work: the owner pays for no server GPU.
  • Four image-upscaling filters (BSD-3 licence): two Fast ones (2.4 MB and 1.2 MB) ship with the page, two High quality ones (33.4 MB and 8.9 MB) download only when chosen.
  • No framework, no build step: HTML, CSS and 14 ES modules served as they are.

3Quyết định thiết kếDesign decisions

Xử lý ngay trong trình duyệtProcess in the browser

Vì saoWhy
Không trả tiền GPU máy chủ, không giữ ảnh của ai, không giới hạn lượtNo server GPU to pay for, no one else's images to hold, no usage cap
Phương án đã loạiRejected alternative
Dịch vụ trả phí theo từng ảnh, ảnh bị gửi điA paid per-image service, with images sent away

Dựng lại các mạng xử lý ảnh bằng thư viện tính toán chạy trong trình duyệt, từ trọng số fp16Rebuild the image networks in a browser compute library from fp16 weights

Vì saoWhy
File nhỏ, không cần công cụ ngoài để chuyển đổi, kiểm soát được bộ nhớ từng mảnhSmall files, no external tool needed to convert, control of memory per tile
Phương án đã loạiRejected alternative
Nạp file mô hình dựng sẵn (nặng hơn, không kiểm soát được bộ nhớ)Loading ready-made model files (heavier, no memory control)

Mọi mảnh ảnh đọc qua cùng một cửa sổ cùng kích thướcEvery tile read through one same-size window

Vì saoWhy
Bộ nhớ GPU được giữ theo kích thước; chỉ một kích thước thì dùng lại đượcGPU memory is kept per size; one size means reuse
Phương án đã loạiRejected alternative
Mỗi kích thước mảnh một cửa sổ (2,7 GB, tab trên điện thoại bị sập)A window per tile size (2.7 GB, tabs crashed on phones)

Bộ lọc lớn đặt ở nơi lưu trữ riêngLarge filters hosted separately

Vì saoWhy
Nơi lưu trang không nhận file quá 25 MiB; repo git nhẹThe page host allows 25 MiB per file; the git repo stays light
Phương án đã loạiRejected alternative
Để chung với trangKeeping them with the page

Không framework, không bước buildNo framework, no build step

Vì saoWhy
Trang chỉ một màn hình; ít bộ phận chuyển động; phát hành là một lần pushA one-screen page; fewer moving parts; releasing is a git push
Phương án đã loạiRejected alternative
React, bundler, npmReact, a bundler, npm

4Cách kiểm chứngHow it is verified

  • Kết quả được so với bản tham chiếu gốc, lệch khoảng 1e-5.
  • Trang được kiểm trong Chrome thật với đầu vào xấu, file hỏng, ảnh quá lớn và mất mạng.
  • Bộ kiểm tra quy tắc được chứng minh bằng 18 lỗi cài cố ý, tất cả đều bị bắt.
  • Output is compared with the original reference, about 1e-5 apart.
  • The page is checked in a real Chrome with bad input, broken files, oversized images and the network down.
  • The rule checker is proven by 18 deliberately planted mistakes, all caught.
