Cách sản phẩm này được làmHow this product is built

Exomaly Remux

Sửa container của file MP4 trước khi đăng lên TikTok, hình và tiếng giữ nguyên từng byte.Fixes the container of an MP4 file before posting to TikTok, picture and sound unchanged byte for byte.

Mở sản phẩmOpen the product →

1Tóm tắtSummary

  • Không mã hoá lại: dữ liệu hình và tiếng của file ra bằng đúng file vào, từng byte, nên chất lượng không bao giờ đổi.
  • Hình và tiếng không rời máy: chỉ phần chỉ mục của file (khối moov) được gửi qua HTTPS tới máy chủ, xử lý trong bộ nhớ và không lưu.
  • Không framework, không bước build. Phông chữ tự lưu, trang không gọi Google Fonts.
  • No re-encoding: the picture and sound data of the output equal the input byte for byte, so quality never changes.
  • Picture and sound never leave the device: only the file's index (the moov box) goes over HTTPS to the server, is processed in memory and is not stored.
  • No framework, no build step. Fonts are self-hosted, the page makes no call to Google Fonts.

4Cách kiểm chứngHow it is verified

  • 190 test Node và 22 test Python phủ xử lý file, máy chủ, cửa hàng và các quy tắc dự án.
  • Luồng trên trang được kiểm trong Chrome thật: chỉ phần chỉ mục được gửi và kết quả khớp từng byte với bản gốc.
  • API được kiểm trong môi trường chạy cục bộ với cơ sở dữ liệu cục bộ.
  • 190 Node tests and 22 Python tests cover file processing, the server, the shop and the project rules.
  • The page flow is checked in a real Chrome: only the index is sent and the output matches the original byte for byte.
  • The API is checked in a local runtime with a local database.
