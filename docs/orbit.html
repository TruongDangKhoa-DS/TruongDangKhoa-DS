Cách sản phẩm này được làmHow this product is built

Exomaly Orbit

Ứng dụng ở khay hệ thống Windows, chỉ đọc, theo dõi nhánh git, commit chờ push và tiến trình nặng trên một máy, báo qua thông báo Windows và bảng điều khiển 3D.A read-only Windows system-tray app that watches git branches, commits waiting to be pushed and heavy processes on one machine, and reports through Windows notifications and a 3D dashboard.

Tự thiết kế cho cá nhân, không phát hành.Self-designed for personal use, not released.

1Tóm tắtSummary

  • Quét các repo git trên máy (nhánh, worktree, commit chờ push, commit chưa gộp), các phiên làm việc đang mở và tiến trình nặng; báo bằng thông báo Windows, cửa sổ bảng điều khiển 3D hai thứ tiếng và một lệnh in trạng thái một dòng.
  • Chỉ đọc và chạy hoàn toàn trên máy: app không push, không fetch, không xoá nhánh, không dừng tiến trình, không mở kết nối mạng.
  • Electron, JavaScript thuần có chú thích kiểu (JSDoc), Three.js và trình test có sẵn của Node; mọi quy tắc của dự án đều có một kiểm tra tự động.
  • Scans the git repositories on the machine (branches, worktrees, commits waiting to be pushed, unmerged commits), the open work sessions and heavy processes; reports through Windows notifications, a bilingual 3D dashboard window and a one-line status command.
  • Read-only and fully local: the app never pushes, fetches, deletes branches or stops processes, and opens no network connection.
  • Electron, plain JavaScript with type annotations (JSDoc), Three.js and Node's built-in test runner; every project rule has an automated check.

3Quyết định thiết kếDesign decisions

Một file trạng thái chung cho cả ba lối vào (khay, cửa sổ 3D, lệnh một dòng)One shared status file for all three entry points (tray, 3D window, one-line command)

Vì saoWhy
Lệnh một dòng chạy ở mọi lượt nên phải nhanh; cửa sổ không cần quyền hệ thốngThe one-line command runs every turn, so it must be fast; the window needs no system access
Phương án đã loạiRejected alternative
Lệnh tự chạy git mỗi lần (chậm 1–2 giây); máy chủ cục bộ (trái quy tắc không mạng)Command running git every time (1–2 seconds); local server (breaks the no-network rule)

Lõi quét không phụ thuộc ElectronScanning core independent of Electron

Vì saoWhy
Test được bằng Node thuần, trên máy nào cũng chạyTestable with plain Node, on any machine
Phương án đã loạiRejected alternative
Viết thẳng trong tiến trình Electron (khó test)Writing it straight into the Electron process (hard to test)

Không tự fetchNo automatic fetch

Vì saoWhy
Fetch ghi vào repo và cần mạng; app hiện tuổi của lần fetch gần nhấtFetching writes to the repository and needs the network; the app shows the age of the last fetch
Phương án đã loạiRejected alternative
Fetch định kỳPeriodic fetch

Lệnh git chạy không giành khoáGit commands run without taking locks

Vì saoWhy
Không tranh khoá với phiên làm việc đang commitNo lock contention with a work session that is committing
Phương án đã loạiRejected alternative
Gọi git bình thườngCalling git normally

4Cách kiểm chứngHow it is verified

  • 954 test tự động phủ lõi quét, app khay, cửa sổ 3D và hai thứ tiếng; chạy khoảng 15 giây lúc máy rảnh.
  • Mỗi bộ kiểm có lỗi cài cố ý phải bị bắt: 56 lỗi vào luật cảnh báo, 95 vào cửa sổ 3D, 36 vào phần tự chạy khi đăng nhập, 7 ca thử tốc độ lệnh một dòng.
  • Luật cảnh báo có 119 ca do tác giả duyệt; cửa sổ 3D được chụp ảnh ở ba chế độ trong Chrome headless để so với ảnh chuẩn.
  • Ứng dụng chạy trên máy, không có trang web để kiểm.
  • 954 automated tests cover the scanning core, the tray app, the 3D window and both languages; about 15 seconds on an idle machine.
  • Each check has deliberately planted bugs it must catch: 56 in the alert rules, 95 in the 3D window, 36 in the start-at-sign-in code, 7 speed checks of the one-line command.
  • The alert rules have 119 author-approved cases; the 3D window is screenshotted in three modes in headless Chrome and compared with reference images.
  • The app runs locally; there is no website to check.
