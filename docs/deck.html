Exomaly Deck

Bàn điều khiển âm thanh cho sự kiện, chạy hoàn toàn trong trình duyệt và không cần mạng.A sound console for live events that runs entirely in the browser and needs no network.

Sắp ra mắt.Coming soon.

1Tóm tắtSummary

  • Mỗi deck là một bài nhạc nền hoặc hiệu ứng, có fade in/fade out riêng; crossfade giữa các bài nhạc nền, phím tắt cho sân khấu, dò nhịp (BPM) và giọng (Tone).
  • Không máy chủ, không tài khoản, không gửi gì ra mạng: nhạc và cấu hình lưu trong trình duyệt của người dùng (IndexedDB). HTML, CSS, JavaScript thuần, không thư viện, không bước build; chép thư mục là chạy, kể cả khi hội trường mất mạng.
  • Thiết kế gốc bởi HoangPham; Exomaly tích hợp và chỉnh sửa.
  • Each deck is a background track or a sound effect with its own fade in and fade out; crossfade between background tracks, stage hotkeys, tempo (BPM) and key (Tone) detection.
  • No server, no account, nothing is sent over the network: music and settings are stored in the user's own browser (IndexedDB). Plain HTML, CSS and JavaScript, no libraries, no build step; copy the folder and it runs, even when the venue has no network.
  • Originally designed by HoangPham; integrated and adapted by Exomaly.

3Quyết định thiết kếDesign decisions

Web tĩnh một trang, mở bằng file://Static single page, opened with file://

Vì saoWhy
Chạy offline tuyệt đối, không phụ thuộc mạng hay tài khoản trong buổi diễn; hai file JS (lõi và giao diện), chép thư mục là chạyFully offline, no dependence on a network or an account during a show; two JS files (core and interface); copy the folder and it runs
Phương án đã loạiRejected alternative
App desktop (Electron): nặng, cần cài đặtDesktop app (Electron): heavy, needs installing

Script cổ điển, không ES module, không bước buildClassic scripts, no ES modules, no build step

Vì saoWhy
file:// chặn nạp module từ file; không build thì không có gì để hỏng trước giờ diễnfile:// blocks module loading from files; with no build there is nothing to break before showtime
Phương án đã loạiRejected alternative
ES module và bộ đóng góiES modules and a bundler

Phát bằng HTMLAudioElement, fade chạy bằng khung hình, tab ẩn thì chạy bằng bộ hẹn giờPlayback with HTMLAudioElement, fades driven by frames, by a timer when the tab is hidden

Vì saoWhy
Nhạc từ URL không hỗ trợ CORS vẫn phát đượcMusic from URLs without CORS support still plays
Phương án đã loạiRejected alternative
Bỏ hẳn đường này: nguồn URL qua Web Audio thì câmDropping this path entirely: URL sources go silent through Web Audio

Đường phát Web Audio (một GainNode mỗi deck, chung một limiter, đồng hồ mức), bật theo khả năng trình duyệt (dò tính năng, không đọc tên trình duyệt)Web Audio output path (one GainNode per deck, one shared limiter, a level meter), turned on by browser capability (feature detection, no browser-name sniffing)

Vì saoWhy
Nhiều deck cùng phát vượt 0 dBFS thì vỡ tiếng; limiter giữ tổng dưới 0,976Several decks playing together go past 0 dBFS and clip; the limiter keeps the mix under 0.976
Phương án đã loạiRejected alternative
Limiter tự viết bằng AudioWorklet (không nạp được khi mở bằng file://); ngưỡng nén dưới 0 dB (tự nâng âm lượng mọi deck)A hand-written AudioWorklet limiter (cannot load when opened via file://); a compressor threshold below 0 dB (raises every deck's volume)

4Cách kiểm chứngHow it is verified

  • 1005 test Node (lệnh node --test "tests/*.test.js") và 298 lỗi cài cố ý, tất cả đều bị bắt; đáp án của luật lõi nằm trong 359 ca vàng do người duyệt, không lấy bằng cách chạy code.
  • So từng ca với bản trước khi tách lõi: 1001 ca cũ giống hệt, 1 ca đổi tên.
  • Trình duyệt thật (Chrome headless): kiểm nâng cấp người dùng cũ 32/32 ý, bố cục và thao tác 54/54 ý cả VI và EN, chính sách bảo mật nội dung (CSP) 11/11 ý.
  • Một lỗi thật mà ca vàng bắt được: bài nhịp mạnh ở 174 BPM bị dò thành 87 BPM, lỗi rộng hơn tên ca (11 trên 36 tempo quét); đã đo trước khi sửa, sửa bằng nội suy đỉnh rồi thêm 7 lỗi cài để canh.
  • 1005 Node tests (command node --test "tests/*.test.js") and 298 deliberate planted faults, all caught; the answers for core rules live in 359 golden cases approved by a person, never taken by running the code.
  • Case-by-case comparison with the version before the core split: 1001 old cases identical, 1 renamed.
  • Real browser (headless Chrome): existing-user upgrade check 32/32 points, layout and interaction 54/54 points in both VI and EN, content security policy (CSP) 11/11 points.
  • A real bug the golden cases caught: a strong-beat track at 174 BPM was detected as 87 BPM, wider than its test name (11 of 36 swept tempos); measured before fixing, fixed with peak interpolation, and 7 planted faults now guard it.
